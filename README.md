## Getting Started

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/dr-ayesha-seecs/ir-course-exercises/blob/main/IR_Exercises_Colab.ipynb)

See [SETUP_FAQ.md](SETUP_FAQ.md) for Colab and local setup.

1. Clone this repository.
2. Complete `exercise1/starter.py` first.
3. Read the `README.md` in each exercise folder for instructions.
4. Run each starter from the repository root, e.g. `python exercise1/starter.py`. Exercises 2 and 3 reuse your Exercise 1 code.
5. Write your results using [REPORT_TEMPLATE.md](REPORT_TEMPLATE.md).
